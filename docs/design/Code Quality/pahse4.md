Phase 4 — Intelligent PHP Refactoring
Objective: Introduce Rector and AST-based transformations.
Examples:
- PHP modernization.
- Simplifying expressions.
- Improving type declarations.
- Removing obsolete constructs.
- Reducing unnecessary complexity.
Each proposed transformation must show:
Reason + affected code + proposed code + risk + diff.
No transformation is applied without explicit developer approval.
Milestone: TAFRA Studio becomes a genuine PHP refactoring assistant rather than only a formatter.
